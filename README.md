# Notification Sound Setter
Created by Ty Paragas

An Android app that plays custom sounds when notifications from selected apps match your rules. Provides a way to setup custom notification categories for apps that don't already provide it or don't provide the desired granularity.

## Core functionality

- Create sound mappings for individual apps using keywords or phrases in notification titles and bodies. Matching ignores case, and any matching title or body keyword can trigger the sound.
- Set one fallback sound per app for notifications that do not match a keyword rule.
- Choose built-in notification sounds or import and preview your own audio files.
- Edit, enable, disable, or delete mappings and manage imported sounds.

## Getting started
Requires Android 10 or later.

1. Open the app and enable notification access when prompted.
2. Allow background operation through the battery optimization settings if needed.
3. Create a mapping, choose an app, add keywords or select **Any notification from this app**, and choose a sound.
4. Save the mapping. The app plays the selected sound when a matching notification arrives.

The original notification sound may also play. **It's recommended that you disable notification sounds for broad categories in the apps you wish to set custom notification sounds for.**  
For example, one who wishes to setup per-person sounds for Instagram messages should disable notification sounds for the broad messages category in Instagram.
